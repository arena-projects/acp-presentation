Push-Token

Mit dem Push-Token meldest du dich beim Einreichen per git push an. Du hast höchstens ein Token; ein neues ersetzt das bisherige.

So verwendest du das Token

  1. Beim ersten git push zu fragt Git nach Zugangsdaten.
  2. Als Benutzername gibst du token ein, als Passwort dein Push-Token.
  3. Der Credential-Manager deines Systems kann das Token speichern, damit du es nicht jedes Mal eingeben musst.

Nach dem Erzeugen eines neuen Tokens musst du den gespeicherten Eintrag aktualisieren. Ein Push mit einem alten Token wird mit remote: Ungültiges Push-Token abgelehnt.
