# Klick-Dummy

Dieser generierte Klick-Dummy enthält einige Funktionen für einen möglichen MVP des Arena-Projekts
"Challenge Plattform". Er zeigt einen Vorschlag für die Web-Oberfläche, besteht aus statischen
Dateien und lässt sich über die [index.html](index.html) im Browser öffnen.

Statt einer echten Anmeldung lässt sich dort eine Rolle wählen. Als Nutzer findet man Challenges
im Katalog, kann die Aufgaben einsehen und Lösungen einreichen: entweder einen Wert direkt
im Formular (z. B. "Vertex Cover" oder "Großes Sudoku") oder Code über einen simulierten `git
push` (z. B. "Bücher-API für den Workshop"). Danach lässt sich die Prüfung live auf der
Ergebnisseite verfolgen; abgeschlossene Ergebnisse zeigen z. B. "URL-Shortener" (nicht bestanden)
und "To-do-API" (Build-Fehler). Als Autor kann man unter "Meine Challenges" eigene Challenges
anlegen, Entwürfe bearbeiten, die Vorschau ansehen und freigeben, Sichtbarkeiten und Teilen-Links
verwalten. Als Gast erlebt man die Plattform so wie jemand, der nur einen Teilen-Link
bekommen hat. Mit der Demo-Leiste am unteren Rand kann jederzeit die Rolle gewechselt,
das Ergebnis der nächsten Prüfung (bestanden, nicht bestanden, Build-Fehler usw.) festgelegt und
alle Eingaben zurückgesetzt werden. Eingaben bleiben nur im Browser gespeichert. Downloads,
Uploads und die eigentliche Prüfung sind nur simuliert.
